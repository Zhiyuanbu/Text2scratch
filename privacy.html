Privacy

Privacy policy

Last updated: February 19, 2026. This page explains what happens locally in the browser, what is stored when you use cloud features, and which third-party services are involved.

1. Local processing by default

text2scratch converts text and Scratch project data in your browser. Local imports, edits, and exports do not require a cloud account.

2. Cloud storage

If you sign in and choose to save a project, project text and related metadata are stored in Supabase under your account. Public visibility only changes when you explicitly create a share link.

3. Downloads

Generated .sb3 and .t2sh files are created in-browser and downloaded directly to your device.

4. Third-party services

The site loads JSZip, Monaco Editor, Supabase, Font Awesome, and Datadog Browser RUM from third-party CDNs. These services may process standard browser and performance metadata according to their own policies.

5. Shared links

Shared links expose the saved project you intentionally publish. Treat share links as public content and avoid publishing sensitive data in project text.

6. Hosting logs

If the site is hosted on GitHub Pages or another provider, that host may collect standard HTTP logs such as IP address, timestamps, and user agent strings.
