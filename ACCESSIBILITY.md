# Accessibility Statement

text2scratch is actively improving keyboard access, live-region announcements, focus handling, and non-visual labeling across the site and workspace.

Current areas of focus:

- Keyboard access for navigation menus, dialogs, and workspace controls
- Screen-reader announcements for status updates, errors, and toast messages
- Clear labels for icon-only controls and form fields
- Contrast and focus visibility across light and dark themes

Known limitations:

- The converter workspace depends on JavaScript and cached assets for its full authoring experience.
- Some legacy browser surfaces remain narrower in scope than the React site shell and may still need incremental accessibility hardening.

Feedback can be opened through the GitHub repository issues page.
