How to read a card

  • Syntax is the exact command form.
  • How to use tells you where the command belongs.
  • Arguments explains the placeholders in order.
  • Meta shows target support, opcode, inputs, and fields.

Common mistakes

  • Putting reporter or boolean commands on their own lines.
  • Using sprite-only commands inside stage_code =.
  • Forgetting the matching end after nested control blocks.
  • Guessing menu values instead of using the listed selectable options.
