Why teams pick this flow

  • Faster than arranging large Scratch scripts by hand.
  • Easier to review, diff, and teach as plain text.
  • Safer to debug because parser feedback points to exact mistakes.

What it does

A production-style workflow for Scratch builders

The product is designed for classrooms, workshops, prototyping, and anyone who prefers structured editing over block dragging.

Author faster

Write stage scripts, sprite scripts, broadcasts, variables, and expressions in a consistent text format.

Validate structure

The compiler output catches missing end blocks, unknown commands, and stage or sprite mismatches before export.

Save and share

Optional Supabase-backed accounts let you save projects to the cloud, generate links, and browse public community examples.

How it works

Four steps from blank file to Scratch project

  1. Write Use text2scratch syntax in the editor. Keep one command per line.
  2. Validate Check compiler output for structure issues, invalid commands, and target mismatches.
  3. Export Download either a real Scratch project .sb3 or a restore-friendly .t2sh.
  4. Run Open the project in Scratch, test the green flag flow, then iterate.
